Free KS3 Binary Cover Lesson: No-Computer Plan, Script + Answers

A complete one-hour KS3 Computing cover lesson on binary numbers that a non-specialist can run in any classroom. It includes timings, what to say, pupil tasks and a full answer key.

You have a Computing class to cover in a normal classroom, with no IT room and possibly no specialist. Binary numbers suit this well. Pupils need only paper and a pen, the topic is on every KS3 Computing scheme of work, and every answer can be checked exactly, so the person covering doesn't need any Computing knowledge.

You can run everything below straight from this page. Copy the tasks onto the board or a worksheet, and use the answer key at the bottom to check work.

Suits: Year 7 or Year 8 (and Year 9 as revision) Length: 60 minutes You need: paper, pens, a board. Scissors are optional.

Before the Lesson (5 Minutes of Prep)

  • Write the place-value row on the board, large: 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1
  • Copy Tasks 1 to 3 onto the board, or print this page.
  • Keep the answer key away from pupils.

Lesson Timings at a Glance

  1. Do-now starter: 5 minutes
  2. Explanation (scripted): 10 minutes
  3. Task 1, binary to denary: 10 minutes
  4. Task 2, denary to binary: 12 minutes
  5. Task 3, secret message: 13 minutes
  6. Exit ticket and pack-up: 10 minutes

1. Do-Now Starter (5 Minutes)

Put this on the board as pupils arrive:

"A light switch can be ON or OFF. How many different patterns can you make with 1 switch? With 2 switches? With 3 switches?"

Let them try for a few minutes, then take answers.

Answers: 1 switch = 2 patterns, 2 switches = 4, 3 switches = 8. Each extra switch doubles the number of patterns.

2. Explanation: What to Say (10 Minutes)

You can read this out more or less word for word.

Say: "Computers are made of millions of tiny switches. Each one can only be on or off. We write on as 1 and off as 0, and this is called binary. Each 1 or 0 is called a bit. Eight bits together make a byte."

Say: "We normally count in denary, which uses ten digits, 0 to 9. Binary uses only two, 0 and 1. To read a binary number, we use this row." (Point to 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1.)

Say: "Each column is worth double the one to its right. Wherever there's a 1, you add that column's value. Wherever there's a 0, you ignore it."

Model one example on the board. Write 00000101 under the row:

  • The 1s are under the 4 and the 1.
  • 4 + 1 = 5

Model one more: 00010010

  • The 1s are under the 16 and the 2.
  • 16 + 2 = 18

Say: "Going the other way, from a normal number to binary, start at 128 and work right. Ask: does this column fit into my number? If yes, write 1 and take it away. If no, write 0. Keep going until you reach the 1 column."

Model: 37

  • 128? No → 0. 64? No → 0. 32? Yes → 1, leaving 5.
  • 16? No → 0. 8? No → 0. 4? Yes → 1, leaving 1.
  • 2? No → 0. 1? Yes → 1, leaving 0.
  • Answer: 00100101

3. Task 1: Binary to Denary (10 Minutes)

Convert each binary number to a normal (denary) number. Show your working by writing down which columns you added.

  1. 0101
  2. 1010
  3. 1111
  4. 00011001
  5. 00101010
  6. 01100100
  7. 10000000
  8. 11111111

Tip for the adult: if a pupil gets 1010 wrong, check they're reading the columns from the right. The rightmost digit is always the 1 column. For short (4-bit) numbers, only the last four columns are used: 8, 4, 2, 1.

4. Task 2: Denary to Binary (12 Minutes)

Convert each number to 8-bit binary. Every answer must have exactly 8 digits, so use 0s at the front to fill the gaps.

  1. 3
  2. 9
  3. 18
  4. 37
  5. 64
  6. 99
  7. 150
  8. 200

Quick check pupils can do themselves: convert their answer back using Task 1's method. If they get the number they started with, it's right.

5. Task 3: Decode the Secret Message (13 Minutes)

Tell pupils: "Each letter has a number: A = 1, B = 2, C = 3, and so on up to Z = 26. Each letter below is written in 5-bit binary, using the columns 16 | 8 | 4 | 2 | 1."

Write the alphabet with its numbers on the board, or let pupils work it out.

Message 1: 01000 00101 01100 01100 01111

Message 2: 00010 01001 01110 00001 10010 11001

Challenge: write your own name, or a word of four or more letters, in 5-bit binary. Swap with a partner and decode each other's.

Extension questions for fast finishers:

  • What is the biggest number you can make with 8 bits?
  • How many different values can 8 bits store? (Careful: count zero too.)
  • Using one hand, with each finger up meaning 1 and down meaning 0, what is the highest number you can count to?
  • Why do you think the letter codes need 5 bits, and wouldn't fit in 4?

6. Exit Ticket (10 Minutes Including Pack-Up)

Pupils answer on a scrap of paper or the back of their sheet and hand it in:

  1. Convert 00001100 to denary.
  2. Convert 21 to 8-bit binary.
  3. In one sentence: why do computers use binary?

Collect these. They tell the class teacher exactly who understood the lesson.

Answer Key

Starter

  • 1 switch = 2, 2 switches = 4, 3 switches = 8

Task 1: Binary to Denary

  1. 0101 = 4 + 1 = 5
  2. 1010 = 8 + 2 = 10
  3. 1111 = 8 + 4 + 2 + 1 = 15
  4. 00011001 = 16 + 8 + 1 = 25
  5. 00101010 = 32 + 8 + 2 = 42
  6. 01100100 = 64 + 32 + 4 = 100
  7. 10000000 = 128
  8. 11111111 = 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255

Task 2: Denary to Binary

  1. 3 = 00000011 (2 + 1)
  2. 9 = 00001001 (8 + 1)
  3. 18 = 00010010 (16 + 2)
  4. 37 = 00100101 (32 + 4 + 1)
  5. 64 = 01000000
  6. 99 = 01100011 (64 + 32 + 2 + 1)
  7. 150 = 10010110 (128 + 16 + 4 + 2)
  8. 200 = 11001000 (128 + 64 + 8)

Task 3: Secret Messages

  • Message 1: 8, 5, 12, 12, 15 = HELLO
  • Message 2: 2, 9, 14, 1, 18, 25 = BINARY

Extension Answers

  • The biggest 8-bit number is 255 (all eight bits set to 1).
  • 8 bits can store 256 different values (0 to 255).
  • One hand (5 bits) counts up to 31.
  • 4 bits only reach 15, which isn't enough for 26 letters. 5 bits reach 31, which is.

Exit Ticket

  1. 00001100 = 8 + 4 = 12
  2. 21 = 00010101 (16 + 4 + 1)
  3. Any sensible answer about computers being made of switches or circuits with two states, on and off (1 and 0). Two states are simple and reliable to store and detect.

Common Mistakes to Watch For

  • Reading the columns the wrong way round. The 1 column is always on the far right.
  • Dropping the leading zeros. 9 written as 1001 is correct binary, but Task 2 asks for 8 bits, so it should be 00001001.
  • Adding the 0 columns. Only columns with a 1 under them count.
  • Starting the subtraction method from the wrong end. For denary to binary, always start from the biggest column (128) and work right.
