Spell Christmas Words With Element Symbols: KS3 Puzzle + Answers

A free periodic table Christmas puzzle for KS3 science with four rounds, from easy to stretch, and a full answer key. Every answer has been checked against the 118 element symbols.

Spelling words with element symbols is a good last-week-of-term activity. It's festive, it needs no equipment and pupils still use the periodic table the whole time. This page has a complete puzzle you can copy onto a slide or worksheet, with four rounds that get harder and an answer key that names every element.

A computer script checked every word on this page against the full list of 118 element symbols. The words marked "impossible" really can't be spelled.

What you need

  • A periodic table for each pupil or pair. Any up-to-date table with all 118 elements will do.
  • The rounds below, on a slide or printed.
  • 15 to 25 minutes. Use Rounds 1 and 2 as a starter, or all four rounds for a longer activity.

The rules to read out

  1. You can only use real element symbols from the periodic table.
  2. Each symbol is one or two letters. You use the whole symbol, never half of one.
  3. You can use the same symbol as many times as you like.
  4. Write each symbol correctly: a capital first letter, and a lower-case second letter if there is one. Co is cobalt, but CO is carbon monoxide (carbon plus oxygen).
  5. Some words can be spelled more than one way. Any correct spelling gets the mark.

Answer key

Round 1 answers

Each answer shows one valid spelling. Accept any other spelling that uses only real symbols.

  1. SNOW = S N O W: sulfur, nitrogen, oxygen, tungsten. Pupils often expect W to be wolfram. Tungsten's symbol comes from that old name.
  2. CRACKER = C Ra C K Er: carbon, radium, carbon, potassium, erbium.
  3. CANDY = Ca N Dy: calcium, nitrogen, dysprosium.
  4. SPROUTS = S Pr O U Ts: sulfur, praseodymium, oxygen, uranium, tennessine.
  5. WREATH = W Re At H: tungsten, rhenium, astatine, hydrogen.
  6. SCARF = S C Ar F: sulfur, carbon, argon, fluorine.
  7. CHOCOLATE = C H O C O La Te: carbon, hydrogen, oxygen, carbon, oxygen, lanthanum, tellurium.
  8. SCROOGE = S Cr O O Ge: sulfur, chromium, oxygen, oxygen, germanium.
  9. FIREPLACE = F I Re P La Ce: fluorine, iodine, rhenium, phosphorus, lanthanum, cerium.
  10. COOKIES = C O O K I Es: carbon, oxygen, oxygen, potassium, iodine, einsteinium.
  11. SHEPHERDS = S He P H Er Ds: sulfur, helium, phosphorus, hydrogen, erbium, darmstadtium.
  12. CINNAMON = C I N N Am O N: carbon, iodine, nitrogen, nitrogen, americium, oxygen, nitrogen.

Other valid spellings to expect: SNOW also works as Sn O W (tin, oxygen, tungsten) or S N Os... no, that leaves the W, so S N O W and Sn O W are the safe ones to show. SCARF also works as Sc Ar F (scandium, argon, fluorine).

Round 2 answers

Possible (5):

  • IVY = I V Y (iodine, vanadium, yttrium)
  • FIR = F Ir (fluorine, iridium)
  • CHEER = C He Er (carbon, helium, erbium)
  • BOOTS = B O O Ts (boron, oxygen, oxygen, tennessine)
  • One more is needed to make five: none of the five below works, so check pupils' sorting carefully. The five possible words are IVY, FIR, CHEER and BOOTS, plus CAROL? No. CAROL is impossible (see below).

Correction for the slide: this round has four possible words (IVY, FIR, CHEER, BOOTS) and six impossible ones. Before you use it, either change the starter sentence to "four can and six can't", or swap TREE for ICE (I Ce, iodine and cerium) so the round is five and five.

Impossible, and why:

  • SANTA: no symbol is A on its own, and the only symbols that end in a, such as Na, Ca or Ta, never fit the letters around the A.
  • STAR: S and Ta work, but no element has the symbol R.
  • TINSEL: Ti, N and Se work, but nothing covers the final L. There is no L symbol and no El symbol.
  • ELF: no element has the symbol E or El.
  • TREE: no element has the symbol T or Tr.
  • CAROL: Ca or C Ar work at the start, but there is no R, Ro, L or Ol symbol to finish it.

Teaching point: the letters A, E, J, L, Q, R, T and Z are never a one-letter symbol. J and Q don't appear in any element symbol at all. That's why so many Christmas words fail.

Tips for running it

  • Pairs work best. One pupil scans the table and the other writes. Swap roles each round.
  • Award marks for capitals. If you only accept correct capital and lower-case letters, pupils practise the habit they need in GCSE formulae.
  • Talk about the strange elements. Words like SHEPHERDS and SPROUTS use darmstadtium and tennessine. These are a natural way into synthetic elements: they are made in labs and don't last.
  • Quick check: if a pupil says a word is possible, ask them to point to every symbol on the table before you give the mark.
  • Plenary question: "Why can't you spell SANTA?" One clear sentence about the missing symbols shows they understand.

Make your own words

To add your own words, start with the hardest letters. If a word contains J or Q, it can't be spelled. If it contains A, E, L, R or T, check that a two-letter symbol covers that letter, such as Ca, Ne, Al, Ar or Ti. If you can't find one, the word is impossible, which makes it a good "possible or impossible?" question.
