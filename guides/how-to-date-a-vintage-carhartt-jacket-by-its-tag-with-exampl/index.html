How to Date a Vintage Carhartt Jacket by Its Tag (With Examples)

A step-by-step way to read the date code on a Carhartt tag, check it against the label, zipper and model number, and describe the jacket's age honestly when you resell it.

Many Carhartt jackets carry a small number on the inside tag that tells you the month and year they were made. Finding that number takes about a minute. The harder part is making sure it really is the date code and not a style or lot number, then checking that the rest of the jacket agrees with it.

About the information here: Carhartt has not published a tag-by-year chart that I could find. This guide draws on published reseller and collector guides, which sometimes disagree. I've noted where they do. Label eras overlap, so treat anything other than a clear date code as a range. This page was written with AI assistance.

The quick answer

Look for a 3-digit or 4-digit number on the white care tag. Read it as month, then year.

  • 1091 = October 1991
  • 1198 = November 1998
  • 0402 = April 2002
  • 1211 = December 2011
  • 591 = May 1991 (some early-1990s tags drop the leading zero)

One published guide says Carhartt adopted this system in the mid-1980s. If that's right, an older jacket may have no code at all. A missing code doesn't prove a jacket is old, though, because tags also get cut out or fade.

Step 1: Find the right tag

Check these places in order:

  1. Inside the neck, at the base of the collar
  2. Inside the side seam, near the hem
  3. Inside a pocket bag, if the tag has been folded or tucked away

On bibs, coveralls and double-front pants, look on an interior side seam or inside the waistband.

Photograph the tag straight on, in bright light, before you wash the jacket. Washing can make a faint code harder to read. Dark, faded print often shows up better in a zoomed-in photo with the contrast raised.

Step 2: Make sure the number is a date code

Tags can carry several numbers. Test each candidate:

  1. Does it have 3 or 4 digits, standing alone? Longer strings are usually style, lot or factory numbers.
  2. Is the month possible? The first two digits must be 01 to 12. A 3-digit code starts with a single month digit, 1 to 9.
  3. Is the year possible? The last two digits should be 85 to 99 or 00 up to the current year, allowing some margin for the uncertain mid-1980s start.
  4. Is it near the care text? Guides place it in the care or production area, often at the top left of the tag.
  5. Is it labeled RN? An RN number identifies the company behind the garment. It doesn't tell you when the jacket was made, so ignore it for dating.

A number like 1491 fails the month test (there's no month 14), so it isn't a date code as written. If two numbers both pass, don't choose yet. Use Step 3 to decide.

Step 3: Check the code against the rest of the jacket

A date only counts if the jacket agrees with it. Go through these cues:

Country and union labels

  • "Made in USA" and "Union Made in USA" point to earlier production, but they don't give a year.
  • One guide puts union labels as typically pre-1995. Others give no cutoff, so treat that year as rough.
  • One guide uses about 2004 as the bracket for USA-made production ending. Another says USA, Mexico and other origins all appear in the early 2000s. Don't date a jacket from country of origin alone.

Model number on the tag

  • J01: firm duck Detroit, often with numbered chest sizes such as 40 or 42
  • J97: sandstone Detroit, introduced in the late 1990s according to one guide, with letter sizes such as M or L
  • J130, J140, J131: Active jacket family
  • C03, C26: Arctic or Traditional coat family
  • C01, C02: chore coat family

So a tag reading J97 with a code that decodes to 1992 is a conflict. One of the two readings is probably wrong.

Label style (a broad range only)

  • 1980s: smaller or older-format care labels, "Made in USA" wording
  • 1990s: white interior care labels with 4-digit codes
  • Early 2000s: fuller care information and more varied origins
  • Modern: multilingual care information and global manufacturing details

Outside logo patch

  • 1980s: smaller woven patch with simpler lettering
  • 1990s onward: bolder gold "C" wave logo on a heavier rectangular patch, a style that continued into later decades

Hardware and lining

  • Heavy brass zippers from YKK or Talon fit older jackets. Light, unbranded hardware doesn't.
  • A plaid or striped blanket lining fits the classic Detroit. Plain gray or synthetic fleece suggests a newer jacket.

None of these cues dates a jacket by itself. You're looking for agreement. If most of them point the same way, trust the date. If they conflict, go back and test the other numbers on the tag. If it's still unclear, describe the jacket by what you can actually see.

Step 4: Decide what you can honestly say

  • Clear code, cues agree: state the month and year as read from the tag.
  • Clear code, one small conflict: say what the tag reads and show a photo of it.
  • No code or missing tag: give a loose range and say it's an estimate, or leave the date out.
  • Under about 20 years old: "vintage" is commonly used for items 20 or more years old, though that's a convention and not a rule. In 2026, a jacket from 2007 would fall short of it, so use its year instead of "vintage".

Worked examples

Example 1: everything agrees Tag reads J01, chest size 42, code 1091, with "Union Made in USA". Blanket lining, brass zipper.

  • Code = October 1991. The model, union label and hardware all fit.
  • Listing wording: "Tag date code 1091 (October 1991). Union made in USA."

Example 2: the dropped zero Tag shows 591, plus a longer style number nearby.

  • The longer number fails the length test. 591 reads as May 1991, which matches the early-1990s habit of dropping the zero.
  • Check that the label style and model number fit before you state it.

Example 3: not quite vintage yet Tag reads J97, size M, code 0307, Made in Mexico.

  • Code = March 2007. That's 19 years old in 2026.
  • Listing wording: "Carhartt J97 Detroit jacket, tag dated March 2007, Made in Mexico." Leave out "vintage".

Example 4: tag cut out No care tag. Brass zipper, striped blanket lining, older-looking woven patch.

  • There's no way to fix a year. The cues suggest an older jacket, but only as a range.
  • Listing wording: "Care tag removed, so exact date unknown. Older-style hardware and lining, shown in photos."

Bidding online? Ask before you buy

Auction photos rarely show the care tag. Send this before bidding:

"Could you send a clear photo of the white tag inside lot ____, including any small 3- or 4-digit number and the country of manufacture? Please also confirm the size on the tag and whether the jacket is lined."

If there's no reply, bid as though the jacket has no readable tag.

What a date doesn't tell you

An older date doesn't guarantee a higher price. Model, lining, size and condition also move the price, so a clean jacket can outsell an older, damaged one. Once you've dated yours, search eBay's sold listings for the same model, lining and size, and compare it only with jackets that match.
