How to Factory Reset a Used Switch Lite Locked by a PIN or Account

Bought a used Nintendo Switch Lite with someone else's profile, Nintendo Account or Parental Controls PIN on it? Follow these steps to clear it, check it worked, and decide what to do if you get stuck.

Auction, thrift and estate-sale consoles often still have the last owner's profile on them. Before you can resell one honestly as "factory reset", you need to know which kind of lock you have and what clears it.

This guide is for a console you legitimately own. Nothing here bypasses Nintendo's security. It uses Nintendo's own reset and PIN-recovery steps. Menu names can vary a little by region and system version.

The short answer

  • Someone else's profile or Nintendo Account, but no PIN prompt: you can usually run the normal factory reset. Nintendo's published steps ask for a Parental Controls PIN if one is set. They don't list the old owner's account password as a step.
  • A Parental Controls PIN you don't know: you must clear the PIN first, because the reset asks for it.
  • Maintenance Mode: this is not a way around a PIN. Nintendo says you'll be prompted for the PIN there too if one is set.

Step 1: Get ready

  1. Charge the console for a while with a known-good USB-C charger. Don't start a reset on a low battery.
  2. Keep your auction invoice or receipt. If you ever need to deal with Nintendo about the console, it's your proof of purchase.
  3. Write down the serial number from the back of the console and keep it with the invoice.
  4. Take the microSD card out. Put it aside for Step 6.
  5. Connect the console to Wi-Fi. Nintendo calls an internet connection "recommended" for this reset, because the console uses it to unlink Nintendo Accounts.
  6. Have a look at what's installed if you're curious, but don't count on keeping any of it. Digital games belong to the old owner's Nintendo Account, not to the console, so they aren't something you can sell.

Step 2: Run the factory reset

  1. On the HOME Menu, open System Settings.
  2. Scroll down to System.
  3. Scroll to the bottom and select Formatting Options. If a PIN prompt appears here, go to Step 3.
  4. Select Initialize Console. Some regions call it Restore Factory Settings.
  5. Read the screen and select Next.
  6. If the console has no internet connection, Nintendo's steps are: select Next, then Cancel, then Continue. The console will try to connect to unlink accounts.
  7. Confirm to finish.

Nintendo says this takes about five minutes on system version 10.0.0 or later. Deleted data can't be recovered. The old owner's Nintendo Account still exists afterward, it just isn't on this console anymore.

If you're ever given the option, do not use "Initialize Console Without Deleting Save Data". It keeps save data and user information. Nintendo says to use the full initialization when selling or giving away a console.

Step 3: Clear a Parental Controls PIN you don't know

These are the steps on Nintendo's Americas support page.

  1. If you can contact the seller, ask first. If they have the Nintendo Switch Parental Controls app linked to this console, they can see the PIN in the app. Auction houses often can't help, but it's worth one message.
  2. On the HOME Menu, select the red Parental Controls icon.
  3. Enter a wrong 4-digit PIN six times until the lockout message appears.
  4. Press the + or - button for Help.
  5. Scroll to Forgot PIN and write down the Inquiry Number.
  6. Do not back out of this screen. If you leave and come back, the number changes and the old one stops working.
  7. Go to Nintendo's online PIN reset tool, which you'll find from its "Forgot Parental Controls PIN" support page. Enter the Inquiry Number. An email address is required. If you can't provide one, contact Nintendo support.
  8. Once you have cleared or changed the PIN, return to Step 2.

Good to know:

  • If the console was linked to the Parental Controls app, Nintendo says resetting the PIN also removes the app link and the app's play history and restrictions.
  • The process can differ outside the Americas. Some regional Nintendo pages describe phone support using the Inquiry Number and serial number. A forum post from a buyer in Germany reported being asked for details belonging to the original owner. If the online tool doesn't work for you, contact Nintendo for your region and be ready to show your invoice.

Step 4: If the console won't reach the HOME Menu

Maintenance Mode can start a reset when normal menus won't load.

  1. Turn the console fully off. Maintenance Mode can't be opened from sleep mode.
  2. Hold volume up and volume down together.
  3. While holding them, press Power.
  4. Keep holding the volume buttons until the Maintenance Mode menu appears.
  5. Select Initialize Console, not the "Without Deleting Save Data" option.

If a PIN is set, you'll be asked for it here, and Step 3 applies. If the console also won't get as far as a PIN screen or Maintenance Mode, treat it as a hardware fault. Don't list it as working.

Step 5: Confirm the reset really worked

Don't take the progress bar's word for it. Check all of these:

  • [ ] The console restarts to the first-time setup screen (language and region).
  • [ ] No old user icons or profiles appear.
  • [ ] No PIN prompt appears when you open Formatting Options.
  • [ ] Old games are gone from the HOME Menu.

Step 6: Deal with the microSD card

Nintendo's reset instructions don't say the reset clears the card, so handle it separately. Either keep the card for yourself, or wipe it before including it. To wipe it on the console, use System Settings > System > Formatting Options > Format microSD Card. Never ship a card you haven't wiped, since it can hold the last owner's screenshots and videos.

Step 7: Check online access before you promise it

A used console may have been banned from Nintendo's online services by a previous owner. A factory reset doesn't necessarily tell you whether this has happened. To check:

  1. Complete setup using your own test Nintendo Account.
  2. Open the Nintendo eShop and see whether it loads.
  3. If you get an error, look up the exact code in Nintendo's error code search. Sellers commonly report 2124-4007 as the code for a banned console. I could not confirm that on a Nintendo page, so treat it as a clue rather than proof.
  4. If the eShop loads, repeat Step 2 to remove your test account. Confirm with Step 5 again.
  5. If it doesn't load and your Wi-Fi is fine, disclose that in the listing and don't call it fully working.

What about "primary console" status?

The old owner's account may list this console as its primary console. This is an account setting rather than a lock on the hardware. Nintendo's factory reset steps don't mention it as a requirement. The old owner can deregister it through the eShop or, without the console, through the Nintendo Account website, which Nintendo limits to once per year. You don't need the old owner's account in order to complete the steps above.

If you can't clear it

Stop and don't improvise. Options, in the order I would try them:

  1. Contact Nintendo support with the Inquiry Number and your invoice.
  2. Contact the seller or auction house, but expect "sold as-is".
  3. Sell it honestly as locked. Set the eBay condition to For parts or not working, and state the fault in the title and description.

Fill-in wording for that listing:

> Nintendo Switch Lite [color], model HDH-001. Sold for parts or repair. This console is locked by a Parental Controls PIN that I don't have, so I could not factory reset it. Tested only as far as: [powers on / screen displays / buttons navigate HOME Menu]. Previous owner's data may still be on the console. No returns for the lock.

Check eBay sold listings for locked or parts-only units before you decide what it's worth. Asking prices often sit well above what actually sells.

Also stop if anything suggests the console was stolen, such as a name and a "reward if found" note on the case. Hand it to the auction house or the police rather than trying to reset it.
