Free Rhythm Counting Cover Worksheet + Answer Key (Non-Musician)

A no-tech, no-instrument rhythm worksheet for KS3 band, orchestra or choir classes, with a full answer key that a cover teacher who can't read music can mark. Copy the questions onto the board or a sheet and the lesson is ready.

If you run a band, orchestra or choir class, it's hard to leave work for cover. The cover teacher usually can't take a rehearsal or read a score, and you probably don't want instruments out without you there. Rhythm counting gets round this. Pupils can do it with a pencil, it supports their ensemble playing, and it can be marked from a list of numbers.

The page below is the whole lesson: a reference card for the board, four sections of questions, a minute-by-minute plan and a complete answer key. All the notes are written as words, not printed notation, so you can copy everything onto a board or into a document without music software.

Before you leave it: a 3-minute checklist

  • Copy the Reference Card onto the board, or print it.
  • Print the questions or write them up. Sections A to D fit on two sides of A4.
  • Leave the Answer Key in a separate envelope or folder for the cover teacher only.
  • Write on the cover note: "No instruments today. This is a silent written lesson."
  • Choose which names the class uses: UK (crotchet, minim) or US (quarter note, half note). The reference card gives both.

Reference Card (copy onto the board)

These are beat values in a time signature where the beat is a crotchet (quarter note). That covers 2/4, 3/4 and 4/4.

  • Semibreve (whole note) = 4 beats
  • Dotted minim (dotted half note) = 3 beats
  • Minim (half note) = 2 beats
  • Dotted crotchet (dotted quarter note) = 1 and a half beats
  • Crotchet (quarter note) = 1 beat
  • Quaver (eighth note) = half a beat
  • Semiquaver (sixteenth note) = a quarter of a beat
  • Rests last as long as the note with the same name. A minim rest = 2 beats of silence.
  • A dot after a note adds half of that note's value again.
  • Time signature: in 2/4, 3/4 and 4/4 the top number is the number of crotchet beats in each bar.

  2. Crotchet + crotchet + minim

  4. Quaver + quaver + crotchet
  5. Semibreve + minim
  6. Dotted crotchet + quaver
  7. Minim + minim rest
  8. Four quavers + minim

Section C: Is the bar correct? (8 marks)

Each bar below has a time signature. Add up the beats, then write Yes if the bar has the right number of beats or No if it doesn't. Show the total.

  1. 4/4: minim, crotchet, crotchet
  2. 3/4: minim, minim
  3. 3/4: dotted minim
  4. 4/4: crotchet, crotchet, crotchet
  5. 2/4: quaver, quaver, crotchet
  6. 4/4: dotted crotchet, quaver, minim
  7. 3/4: crotchet, crotchet rest, crotchet
  8. 4/4: semibreve, crotchet

Section D: Fill the gap (6 marks)

Write ONE note that completes the bar.

  1. 4/4: minim, crotchet, ___
  2. 3/4: crotchet, ___
  3. 4/4: dotted minim, ___
  4. 4/4: ___ (the whole bar is one note)
  5. 2/4: quaver, quaver, ___
  6. 4/4: dotted crotchet, ___, minim

Extension: Write your own (no marks, for fast finishers)

  • Write four bars of 4/4 using at least one minim, one dotted crotchet and one rest. Under each bar, write the beat total to prove it adds up to 4.
  • Swap with a partner and check each other's bars using the reference card.
  • Choir version: write the words of the first line of a song your choir sings, and give each syllable a note value so the line fills two bars of 4/4.

Minute-by-minute plan (for a 50 to 60 minute lesson)

  1. 0 to 5 minutes: Take the register. Seat pupils in their usual places, or alphabetically if there is no seating plan. Say: "This is a silent written lesson. There are no instruments today."
  2. 5 to 10 minutes: Read the reference card aloud, or ask a pupil who plays an instrument to do it. Do Section A question 1 together as an example.
  3. 10 to 25 minutes: Pupils work through Sections A and B alone, in silence.
  4. 25 to 40 minutes: Pupils do Sections C and D. They can whisper to the person next to them during these sections.
  5. 40 to 50 minutes: Read out the answers from the key. Pupils mark their own work in a different colour and write a score out of 32 at the top.
  6. 50 minutes to the end: Fast finishers do the extension. Collect all sheets for the class teacher.

Behaviour note for the cover teacher: You don't need to know any music. Every answer is a number, "Yes/No" or a note name, and the key below lists them all. If a pupil says "that's not how my teacher does it", note the question and leave it for the class teacher.

Marking tip: Some pupils will write a rest with the same value instead of a note (for example "crotchet rest" for D1). That still completes the bar, so give the mark. Accept US names too: quarter note = crotchet, half note = minim, whole note = semibreve, eighth note = quaver.

How to make this fit your ensemble

  • Band and orchestra: Add a Section E. Copy two or three bars from a piece you're rehearsing, written as note names, and ask pupils to count the beats. That ties the cover lesson to the rehearsal you'll pick up next time.
  • Choir: The extension task with song lyrics links rhythm to how text is set to music. You can also ask pupils to write how many beats each word gets in a phrase you already sing.
  • Mixed-ability classes: Less confident readers can leave out semiquavers and dotted notes. Stronger pupils can try 6/8. Remember to tell them that in 6/8 the quaver is counted as the unit, so the reference card values work differently.
  • Next lesson: Get pupils to clap one of their extension rhythms to the group. That checks the written work and warms up the ensemble at the same time.

Common mistakes to look for when you mark

  • Forgetting that rests count. Pupils often skip rests when they add up a bar (Section C, question 7).
  • Dot confusion. A dot adds half the note's value, not one beat. A dotted crotchet is 1½, not 2.
  • Mixing up minim and semibreve. If a pupil gets these the wrong way round, they will get several Section B answers wrong in a predictable way. Look for this when you mark.
  • Reading the bottom number of the time signature as the beat count. It's the top number that tells you how many beats are in a bar.

You can reuse this worksheet whenever cover comes up. Change the note combinations in Sections B to D and you have a fresh version with the same reference card and the same marking method.
